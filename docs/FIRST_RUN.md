# Первый запуск на ПК (Windows 11)

Проверка с настоящим Telegram. Публикации идут только в тестовый канал **@whythefolio**.

## 0. Новый токен бота

Токен вставляется только в `.env` на ПК: не отправляйте его в чаты, на скриншоты и в репозиторий. Если токен где-то засветился, в @BotFather выполните `/revoke` → выберите бота → вставьте новый токен сразу в `.env`.

## 1. Установка

1. [Node.js 22 LTS](https://nodejs.org) и [Git](https://git-scm.com).
2. В PowerShell:
   ```powershell
   git clone https://github.com/whytheweakest-glitch/whytheposter
   cd whytheposter
   copy .env.example .env
   npm ci
   ```

## 2. Заполнить .env

Откройте `notepad .env` и задайте:

- `SESSION_SECRET` — любая длинная случайная строка (40+ символов);
- `TELEGRAM_BOT_TOKEN` — новый токен;
- `AI_PROVIDER=disabled` на первый запуск (модель подключим после выбора под видеокарту).

## 3. Узнать свой ID и ID тестового канала

1. Добавьте бота в **@whythefolio** администратором с правом «Публикация сообщений».
2. Напишите боту в личку любое сообщение.
3. Выполните (бот пока не запущен):
   ```powershell
   npm run setup:check -- @whythefolio
   ```
4. Впишите показанные значения в `.env`: свой ID в `OWNER_TELEGRAM_IDS`, ID канала в `TEST_CHANNEL_ID`. Повторите команду: все строки должны быть с ✓.

## 4. База, образец стиля, запуск

```powershell
npm run db:migrate
npm run db:seed
npm run import:reference -- https://t.me/whytheweekest
npm run build
npm run os
```

Dashboard: http://localhost:3000. Вход: напишите боту `/login` и откройте ссылку на этом же ПК.

## 5. Сценарий проверки (по критериям MVP)

1. С iPhone отправьте боту ссылку → бот отвечает «Сохранено» и карточкой.
2. Отправьте ту же ссылку ещё раз → «Уже есть», дубликата нет.
3. Отправьте альбом из 2–3 фото → один материал.
4. В Dashboard → Входящие: материалы на месте.
5. «Создать черновик» → напишите текст → «Отправить на проверку».
6. В боте пришло превью с кнопками. Нажмите «Подтвердить» → через ~15 секунд пост в @whythefolio.
7. Пост в «Архиве» со ссылкой на сообщение в канале.
8. Остановите `npm run os` (Ctrl+C), отправьте боту ссылку, запустите снова → сообщение не потеряно.

Напишите, какой шаг не прошёл, и пришлите текст из окна терминала (токена в логах нет).

## 6. Локальная модель (RTX 3050)

1. Узнайте объём видеопамяти: `nvidia-smi` в PowerShell, строка `MiB` (например, `8192MiB` = 8 ГБ).
2. Установите [Ollama](https://ollama.com/download) и скачайте модель под эту память:

   | Видеопамять | Модель | Команда |
   |---|---|---|
   | 8 ГБ (обычная настольная 3050) | qwen2.5:7b-instruct | `ollama pull qwen2.5:7b-instruct` |
   | 6 ГБ | qwen2.5:7b-instruct (медленнее) или qwen2.5:3b-instruct | `ollama pull qwen2.5:3b-instruct` |
   | 4 ГБ (ноутбучная 3050) | qwen2.5:3b-instruct | `ollama pull qwen2.5:3b-instruct` |

3. В `.env`: `AI_PROVIDER=ollama` и `AI_MODEL=` имя модели из таблицы. Перезапустите `npm run os`.
4. Проверка: в редакторе поста «Варианты от AI» → через минуту появятся 1–3 варианта. Если долго, поднимите `AI_TIMEOUT_MS`.

Модель работает только на вашем ПК, токены не тратятся. Пост всё равно публикуется только после вашего подтверждения.
