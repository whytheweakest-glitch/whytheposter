# Отчёт: Этап 1 (MVP), 09.11.2026

## Что сделано

Работающее ядро системы: бот, Dashboard, worker, локальная модель, публикация с обязательным подтверждением. Код лежит в локальном git-репозитории (GitHub-репозиторий ещё не создан).

## Технологии

Next.js 15, React 19, TypeScript, Prisma 6 + SQLite (WAL), grammY, Ollama (локальная модель, по умолчанию `qwen2.5:7b-instruct`), zod, pino, Vitest, Playwright.

## Что работает (проверено)

| Критерий MVP | Статус | Как проверено |
|---|---|---|
| 1–2. Ссылка боту сохраняется | Код готов | Unit-тесты разбора сообщений; на реальном боте не проверялось, бота ещё нет |
| 3. Материал в Dashboard | Да | e2e в браузере |
| 4. AI предлагает категорию и описание | Да, с подменённой моделью | Integration-тест; с реальной Ollama не проверялось (нужна видеокарта ПК) |
| 5–7. Черновик, редактирование, автосохранение, предпросмотр | Да | e2e |
| 8. Публикация только после явного подтверждения | Да | 16 integration-тестов + e2e (без галочки подтверждения нет) |
| 9. Опубликованное в архиве | Да | e2e |
| 10. Повторная ссылка не плодит дубликаты | Да | Integration (в т.ч. 5 одновременных отправок) + e2e |
| 11. Сбой внешних сервисов не теряет материалы | Да | Integration: AI недоступен → материал сохранён, задача повторится |
| 12. Секреты не в Git и логах | Да | `.env` в `.gitignore`, маскировка токена в логах, e2e: токен не виден в Настройках |

Дополнительно: защита от двойной публикации (условный захват), статус «Результат неизвестен» при обрыве связи без автоповтора, снятие подтверждения при правке, отдельное разрешение на основной канал, мягкое удаление с подтверждением, журнал действий, ежедневный бэкап SQLite, импорт канала-образца для стиля.

## Тесты

- `npm test`: 50 из 50 (unit и integration).
- `npm run typecheck`, `next build`: без ошибок.
- Сквозной сценарий в Chromium против поддельного Bot API: 16 шагов от входа до публикации и архива, плюс мобильный вид iPhone без горизонтальной прокрутки.

## Что ещё не работает или не проверено

- Реальный Telegram: нет тестового бота и канала. Первый запуск с ними обязателен до использования.
- Реальная локальная модель: не выбрана, ждём характеристики видеокарты.
- Альбомы (несколько фото в одном сообщении) сохраняются как отдельные материалы; публикация пока только текст или одно фото.
- Видео и документы сохраняются, но публикуются только как текст поста (отправка видео не реализована).
- Файлы больше 20 МБ бот скачать не может (ограничение Bot API): сохраняется только ссылка на сообщение.
- Транскрибация голосовых, извлечение текста со страниц, полный календарь, аналитика: Этапы 2–4.
- Визуальный стиль временный, ждём Figma.
- ESLint не настроен; e2e-сценарий пока скрипт, не набор Playwright-тестов в репозитории.
