# WHYTHEWEAKEST OS

Личная редакционная система для Telegram-канала WHYTHEWEAKEST: бот собирает находки, Dashboard помогает превратить их в посты, локальная модель предлагает категории и варианты текста. **Ни один пост не уходит в канал без явного подтверждения владельца.**

## Что внутри

| Процесс | Команда | Что делает |
|---|---|---|
| Dashboard | `npm run start` (или `npm run dev`) | Обзор, Входящие, Публикации и редактор, Календарь, Архив, Идеи, Настройки |
| Бот | `npm run bot` | Принимает ссылки, текст, фото, видео, документы, голосовые, альбомы; кнопки подтверждения; `/login` |
| Worker | `npm run worker` | Скачивает файлы, зовёт локальную модель, публикует подтверждённые посты, делает бэкапы |

Стек: Next.js 15, React 19, TypeScript, Prisma 6 + SQLite, grammY, Ollama (локальная модель), Vitest, Playwright.

## Запуск на Windows 11

1. Установите [Node.js 22 LTS](https://nodejs.org) и (для AI) [Ollama](https://ollama.com).
2. В папке проекта:
   ```powershell
   copy .env.example .env
   notepad .env        # заполнить SESSION_SECRET, TELEGRAM_BOT_TOKEN, OWNER_TELEGRAM_IDS, TEST_CHANNEL_ID
   npm ci
   npm run db:migrate
   npm run db:seed
   npm run build
   ```
3. Модель: `ollama pull qwen2.5:7b-instruct` (или другая, под вашу видеокарту; имя в `AI_MODEL`). Без Ollama всё работает, просто без подсказок AI (`AI_PROVIDER=disabled`).
4. Запустите всё одной командой `npm run os` (или двойным кликом по `start.bat`). Упавший процесс перезапускается сам, Ctrl+C останавливает всё. По отдельности: `npm run start`, `npm run bot`, `npm run worker`.
5. Напишите боту `/login`, откройте ссылку. Dashboard: http://localhost:3000.

Пошаговый первый запуск с проверкой бота и канала: [docs/FIRST_RUN.md](docs/FIRST_RUN.md). Команда `npm run setup:check -- @канал` покажет ваш Telegram ID, ID канала и права бота.

**Где взять значения для .env.** Токен: @BotFather. Свой Telegram ID: например, @userinfobot. ID канала: перешлите пост из канала боту @userinfobot или посмотрите в веб-версии Telegram (вида `-100…`). Бота нужно добавить администратором тестового канала с правом публиковать.

**С iPhone.** Бот работает отовсюду. Чтобы открыть Dashboard с телефона, ПК должен быть доступен: проще всего [Tailscale](https://tailscale.com) на ПК и iPhone, тогда `APP_URL=http://<имя-пк>:3000`.

## Форматы постов

Формат определяется по вложениям, которые вы отметили в редакторе: без вложений текст (до 4096 символов), одно фото, видео или файл с подписью, 2–10 фото и видео альбомом (подпись до 1024 символов). Альбом, присланный боту, сохраняется одним материалом. Из фото перед отправкой удаляются EXIF и GPS.

## Безопасность публикаций

- Подтвердить пост можно только отдельным действием: галочка + кнопка в Dashboard или кнопка «Подтвердить» под превью в боте.
- Подтверждение привязано к хешу содержимого. Любая правка текста, фото или канала снимает его.
- Публикация идёт в **тестовый канал**. Основной канал создаётся выключенным; чтобы публиковать в него, нужны и `MAIN_CHANNEL_PUBLISH_CONFIRMED=true`, и включение в Настройках вводом слова ВКЛЮЧИТЬ.
- Если связь оборвалась во время отправки, пост получает статус «Результат неизвестен» и больше не отправляется сам. Вы проверяете канал и отмечаете, вышел он или нет.
- Отправка, сохранение, перенос в календаре и действия AI подтверждением не являются.

## Стиль из канала-образца

Публичный канал импортируется по ссылке: `npm run import:reference -- https://t.me/имя_канала` (читаются публичные посты из веб-превью t.me). Для закрытого канала экспортируйте его в Telegram Desktop (⋯ → Экспорт истории → JSON) и укажите путь к `result.json`. При генерации черновика модель получает 5–10 самых похожих постов образца как примеры стиля.

## Данные и бэкапы

- База: `prisma/data.db` (SQLite). Файлы вложений: `storage/`. Логи: вывод процессов.
- Бэкап базы раз в сутки в `backups/` (хранятся 14 копий), вручную `npm run backup`. Папку `storage/` копируйте вместе с бэкапами.
- Восстановление: остановите процессы и замените `prisma/data.db` файлом из `backups/`.

## Тесты

```bash
npm test            # unit + integration (временная SQLite, поддельный Telegram и AI)
npm run typecheck
npm run lint
npm run build && npm run test:e2e   # браузер: от ссылки до публикации, против поддельного Bot API
```

Реальный Telegram в тестах не используется. На GitHub те же проверки плюс поиск секретов (gitleaks) запускаются для каждого PR.
